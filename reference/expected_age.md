# Expected age within range assuming exponentially distributed pop

Expected age within range assuming exponentially distributed pop

## Usage

``` r
expected_age(age_lower, age_upper, average_age)
```

## Arguments

- age_lower:

  Lower bound of age range (can be a vector)

- age_upper:

  Upper bound of age range (can be a vector)

- average_age:

  Average age of population
