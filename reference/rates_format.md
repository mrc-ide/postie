# Format rates

Create rates from counts and specifies age output units.

## Usage

``` r
rates_format(x, clinical_cols, severe_cols, denominator_cols, ages_as_years)
```

## Arguments

- x:

  Input data.frame

- clinical_cols:

  Clinical incidence column names

- severe_cols:

  Severe incidence column names

- denominator_cols:

  Denominator column names

- ages_as_years:

  Convert ages to be in units of years
